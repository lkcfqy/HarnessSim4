# InspectBot direct MuJoCo execution protocol

Protocol frozen on 2026-08-27 after a one-seed reachability-only pilot and before the
formal 20-seed run. The pilot used seed 78000000 solely to verify that all 12 fixture
sites are reachable; it did not change a policy, score, threshold, topology, or outcome.

## Purpose

The audit asks whether active decisions driven by frozen real-image detector scores can
be executed as bounded 3-D scanner motions in an independent MuJoCo scene containing a
UR5e visual twin, dual-lens inspection head, cable elasticity plugin, branched fixture,
and the frozen 12-site risk topology.

## Frozen setup

- Formal seeds: 78000100--78000119, a disjoint subset of deployment-v2 scenarios.
- Policies: topology-risk, nearest-unvisited geometry, coverage-first uncertainty, and
  random scan.
- Budgets: 4, 8, 12, and 16 observations.
- Score cache SHA-256:
  `e3ce8b2c9d43dff9c0992a7e0664e614148268e5cf6366d94f84d225707040a5`.
- View order, score fusion, detector threshold, policy equations, risks, and severities
  are identical to deployment-v2.
- Each task-space motion advances by at most 0.025 m; every increment contains four
  MuJoCo physics steps. A scan is accepted only if the mocap field-of-view site is within
  0.003 m of the target site.
- The scanner-motion loop stops at 0.001 m mocap error. The detailed arm is synchronized
  by inverse kinematics and remains collision-disabled so it cannot silently alter the
  cable benchmark physics.

## Acceptance tests

The formal execution audit passes only if:

1. all 320 policy-budget records report successful native reach;
2. maximum task-space field-of-view error is at most 0.003 m;
3. maximum UR5e visual end-effector IK error is at most 0.005 m;
4. all MuJoCo states remain finite;
5. for the same seed, policy, and budget, every perception/allocation metric matches the
   deployment-v2 CSV exactly; only world-space travel and execution diagnostics may
   differ.

No superiority test is attached to this execution audit because the performance rows
are deliberately the same closed-loop decisions as deployment-v2. The new evidence is
3-D reachability, bounded motion, path length, numerical stability, and visual execution.

## Claim boundary

MuJoCo supplies current site poses and executes motion, while detector scores are replayed
from held-out real images rather than generated by rendered camera frames. The UR5e is a
visual IK twin rather than a torque-controlled collision model. Passing this protocol is
cross-system execution evidence, not real-robot timing, collision safety, calibration,
camera, or factory evidence.
