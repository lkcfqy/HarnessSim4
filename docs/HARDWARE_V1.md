# 首台端子插入原型：硬件与接口建议

## 最小可行台架

| 模块 | 建议能力 | v0 目的 |
|---|---|---|
| 6 轴协作臂或小型工业臂 | 负载 3–5 kg；重复定位优先；支持外部实时控制 | 完成接近、对准、插入和退出 |
| 末端夹持/端子治具 | 先用专用可换型夹具，保留柔顺结构安装位 | 降低首版供料和抓取不确定性 |
| 6 轴力/力矩传感器 | 量程覆盖插入力且小量程分辨率足够 | 接触检测、限力、偏插识别和锁止特征 |
| 固定工业相机 | 全局快门、稳定镜头、固定曝光 | 护套/夹具定位和过程记录 |
| 腕部相机 | 小视场近景；刚性安装 | 端子尖端与孔位精对准 |
| 光源 | 漫射穹顶或同轴/环形组合，可锁定亮度 | 抑制金属端子反光和黑色塑料欠曝 |
| 护套夹具 | 基准明确、可测重复定位、快换 | 把视觉误差和夹具误差分开 |
| 工控机/工作站 | 先满足采集、同步和推理；GPU 可后加 | 避免在算法未定型时过度采购 |
| 安全系统 | 急停、限速、限力、安全空间、门禁/扫描 | 真机试验的前置条件 |

## 推荐的分阶段集成

### v0：验证插入闭环

人工装载端子和护套；固定相机定位护套；机器人执行预编程接近，力控完成最后几毫米，
记录全过程。这个版本用于建立真实基线和误差预算。

### v1：增加视觉自适应

增加腕部相机和端子/孔位姿估计，对夹具偏移和线缆回弹实时修正。此时再比较视觉伺服、
模仿学习和模型预测控制。

### v2：增加供料与换型

连接德丰已有送线、剥皮、压接或中转机构；设计快换夹具和 SKU 配方；建立异常恢复与
设备维护界面。只有在 v0/v1 的插入可靠性达标后再投入这一阶段。

## 机械和控制接口先冻结什么

- 机器人基座、夹具、相机和护套基准的坐标系命名；
- 端子允许夹持区域、插入轴、最大力/力矩、最大重试次数；
- 相机触发、控制器状态和力传感器的硬件时间戳；
- 每个 SKU 的预备位、接触搜索范围、插入深度和退出路径；
- 任何超限时的安全停止状态和恢复权限。

不要先根据“机械臂标称重复精度”推导整机能插入。最终误差还包含夹具、手眼标定、端子
夹持、视觉、结构挠曲和线缆侧向力，必须用台架做完整误差预算。
