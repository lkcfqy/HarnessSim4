# 四机器人任务定义

## 统一主线

四个机器人并不是四个互不相关的产品，而是一条从“看懂线束”到“完成复杂装配”的难度
课程。统一对象表示是带语义的图：粒子/关键点为节点，线缆段为边，端子、卡扣、分支和
目标位保留身份标签。

## 1. InspectBot

- 输入：线束图、关键检查位、相机位姿和检查历史；
- 动作：二维相机目标位置与拍摄触发；
- 随机化：线束形状、关键位偏差、缺陷数量、视野和检测噪声；
- 成功：覆盖全部关键位、缺陷召回率 1.0、精确率不低于 0.8；
- 论文问题：拓扑先验能否比等距扫描用更少视图取得更高缺陷召回率？

## 2. InsertBot

- 输入：柔性线缆节点、端子位姿、护套孔位/插入轴和机械臂末端；
- 动作：末端二维目标、端子角度和夹持状态；
- 随机化：护套位置/角度、线缆曲率/刚度、通道间隙和运动速度；
- 成功：端子位置和角度连续四步处于公差内并触发锁止；
- 论文问题：显式插入轴与拓扑端点表示能否降低峰值接触力并提高跨位姿泛化？

## 3. RouteBot

- 输入：线缆图、按工艺排序的卡扣、每个卡扣对应的语义线段和抓持状态；
- 动作：末端二维目标与夹持状态；
- 随机化：卡扣位置、障碍、线缆刚度、初始曲线和间隙；
- 成功：所有卡扣均装入正确的语义线段，而非只有几何覆盖；
- 论文问题：只看几何最近点为何会产生“看起来装好、拓扑却错误”的失败？

## 4. BranchBot

- 输入：多分支线束图、分支身份、双臂末端和目标位；
- 动作：两只机械臂的二维目标与夹持状态；
- 随机化：初始交叉、目标偏移、分支刚度和双臂速度；
- 成功：语义分支到达各自目标、交叉数为零且稳定四步；
- 论文问题：分支身份和图结构能否避免最近邻分配造成的语义交换？

## 统一动作/评测原则

环境接口遵循 Gym 风格，但不强制安装 Gymnasium。所有策略在相同任务、难度和 seed 上
成对运行。主指标为成功率，另报任务特定指标、步数、奖励和失败类型。

Topology 策略使用语义节点和目标对应；Geometry 策略只使用坐标；Random 策略用于检查
任务是否被奖励漏洞轻易攻破。后续学习方法必须和这三组诊断基线共同报告。
